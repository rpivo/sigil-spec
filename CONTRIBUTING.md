# Contributing

This is an early-stage proposal, not a maintained standard. The most valuable contribution
right now is a good argument that it is wrong.

## Especially wanted

- **Corrections to [docs/02-prior-art.md](docs/02-prior-art.md).** If a system already does
  this, or an entry misstates what a standard does, that is the highest-value issue you can
  file.
- **Evidence on the central tradeoff.** Open question 1 in
  [docs/notes/open-questions.md](docs/notes/open-questions.md) asks whether a full
  cryptographic payload can be carried imperceptibly and survive commercial encoding. Any
  measurement, published result, or practical experience bearing on this is worth more than
  design discussion.
- **Domain experience.** Mastering engineers, post supervisors, and anyone who has watched
  metadata die in a delivery pipeline.
- **Patent landscape.** Watermarking is densely patented. Pointers to relevant prior filings
  are useful.

## Less useful right now

Detailed spec text. The technical foundations are unresolved and drafting normative language
before settling the open questions would encode guesses as decisions.

## How

Open an issue. For anything substantial, an issue before a pull request will save time.

## Tone

Claims in this repository should be falsifiable and sourced. Where something is unknown, it
should say so rather than gesture at confidence it has not earned.
